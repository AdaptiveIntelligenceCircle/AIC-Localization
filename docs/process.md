# Translation Process

## 1. Select scope

- One document or one coherent section per unit of work.
- Confirm it is on the priority list or justified as a new need.

## 2. Prepare

- Locate the English canonical text (or the marked source).
- Read the relevant glossary entries.
- Note any under-claim, pre-Covenant, or “not legal advice” sentences — these must survive.

## 3. Translate

- Prefer accuracy and caution over elegance.
- Reuse glossary terms.
- If a term has no good equivalent, keep the English term and add a short explanation on first use.
- Do not add promises (mainnet, compliance, immunity) that the source does not make.

## 4. Self-check

- [ ] Disclaimers present where the source has them
- [ ] Core terms match glossary
- [ ] No accidental strengthening of claims
- [ ] Links and references still make sense
- [ ] Translator notes added for genuine ambiguities

## 5. Submit

- Place files under `locales/<lang>/…`
- Update status
- Open PR with: source reference, language, quality level claimed (usually “draft”), and any open questions

## 6. Review

- Reviewer checks fidelity and under-claim posture.
- Prefer bilingual review when available.
- Merge only when acceptable; “perfect” is not required for draft, but misleading strength is not acceptable.

## Machine translation

Machine translation may be used as a **starting point** only.  
Priority documents require human review before being marked `reviewed` or `stable`.
