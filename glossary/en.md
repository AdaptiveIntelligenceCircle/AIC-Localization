# Glossary (English) — Core AIC terms

Stable short definitions for translators and readers.  
These are orientation definitions, not exhaustive legal or formal specifications.

| Term | Short definition |
|------|------------------|
| **Adaptive Intelligence Circle (AIC)** | Independent, open, non-profit-oriented effort toward ethical coordination infrastructure and related public materials. |
| **Third Path** | Orientation that refuses both pure state capture and pure commercial rule-power over the protocol. |
| **Ethical Kernel** | Design layer that evaluates actions toward Allow / Deny / NeedHuman near authorization paths. |
| **NeedHuman** | Decision outcome requiring human judgment before further automated progress; intended to be non-bypassable. |
| **Fail-closed** | Default posture: when conditions for permission are not met, deny or restrict rather than allow. |
| **Human Meaning Network (HMN)** | Orientation toward preserving and coordinating human meaning; second mission layer after integration themes. |
| **World Meaning Infrastructure (WMI)** | Long-horizon framing for meaning-preserving infrastructure; not a claim of completed deployment. |
| **Entity ≠ immunity** | Principle that organizations or persons do not become immune from law or criticism by virtue of project participation. |
| **No token rule-power** | Protocol rules are not sold via tokens or payment weight. |
| **Under-claim** | Public communication discipline: state less than the maximum rhetorical claim; prefer accuracy over hype. |
| **Pre-Covenant** | Status before explicit Covenant declaration; main surface not declared until criteria are met. |
| **Covenant** | Criteria-gated declaration of a main surface; not declared merely by repository existence. |
| **Parallel TestNet** | Experimental networks that may run in parallel; isolation and default-deny bridging are design concerns. |
| **SSI** | Self-sovereign identity concepts (bind / revoke / rotate) as used in AIC designs — abstract in formal models. |
| **Public Digital Infrastructure (PDI)** | Orientation toward inspectable, capture-resistant digital layers serving broad coordination interests. |
| **Start-Here** | Beginner orientation path for new contributors. |

When translating, keep the English term on first use if the local language rendering is not yet stable, then use the glossary equivalent.
