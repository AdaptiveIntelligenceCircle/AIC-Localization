# Tiếng Việt (vi)

Tài liệu định hướng AIC bằng tiếng Việt.

**Lưu ý quan trọng**

- Tiếng Anh là ngôn ngữ chuẩn (canonical) khi có xung đột nghĩa kỹ thuật hoặc quy phạm.
- Mọi bản dịch đều **không phải tư vấn pháp lý**.
- Trạng thái dự án: **pre-Covenant**, under-claim — chưa tuyên bố mainnet / Covenant.
- Thực thể ≠ miễn trừ (entity ≠ immunity).
